Photos Archive Exporter

一个原生 macOS 工具，用于从 Apple「照片」当前图库中导出原始照片和视频资源，并整理成按日期归档的普通文件夹。

下载最新版 查看 GitHub 仓库

下载文件

在 Release 页面下载：

PhotosArchiveExporter-v0.3.1-macos-universal.zip

这个包是 macOS 通用版，同时支持 Apple silicon arm64 和 Intel x86_64。

快速使用

  1. 在 Apple「照片」中打开你要导出的图库。
  2. 启动 Photos Archive Exporter.app。
  3. 授权 Photos 访问权限。
  4. 选择导出目标文件夹。
  5. 点击 Scan Library。
  6. 点击 Start Full Export。
  7. 运行期间可以在顶部进度条查看已处理数量和百分比。
  8. 导出后可点击 Analyze Exported Photos，对本次导出的图片运行本地 Face Analysis。

导出结果

导出完成后，App 会显示本次运行结果，包括失败、警告、重复资源和改名冲突。对应的 JSON 和 CSV 报告仍会保存在目标目录的 _photos_archive_exporter 文件夹中。Face Analysis 会额外生成本地人脸检测报告。

安全原则

  • 只读访问 Photos 图库。
  • 不删除、不编辑、不移动 Photos 中的资产。
  • 不解析 .photoslibrary 内部私有数据库。
  • 不自动删除重复文件。
  • Face Analysis 只在本机运行，不识别人物身份，不上传图片。
  • 重复内容会被保留，并在报告中标记。

当前限制

  • 需要先在 Apple「照片」中切换到目标图库。
  • 需要原片已经保存在本机。
  • 暂不处理 iCloud 原片自动下载。
  • 暂不导出编辑后版本。
  • Face Analysis 不做人物身份识别。
  • 当前版本尚未做 Developer ID 公证。
